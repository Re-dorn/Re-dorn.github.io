关于

这里是一份更私人一点的说明。

Lyreyja 是这个小站的作者。比起完整简历，这里更像一张站内名片：记录我如何折腾工具、搭建网站、玩游戏、理解系统，也记录一些当时没被整理进正式文章里的想法。

我喜欢把事情拆开看清楚，也喜欢在踩坑之后留下能复用的路径。很多文章都来自这种状态：遇到问题，试很多办法，最后把过程和判断写下来，给未来的自己少走一点弯路。

写作偏好 #

我更在意文章是否真的留下了判断过程，而不是把每一步都写成教程。能解释为什么选这个方案、为什么放弃那个方案，比单纯贴命令更有价值。

也因此，这里不会刻意追求“资料库”式的完整。它更像一组当时当地的记录：问题是什么，我怎么理解它，最后又为什么这么处理。

站点来源 #

这个站最早来自 Hexo/Hugo 时代的旧内容，现在迁移到一个更轻的 Vue / Vite / Vite-SSG Markdown 站点。视觉上参考 Antfu 和 Pseudoyu 那类个人站：少一点装饰，多一点清晰的节奏。

如果之后这个站变得更完整，首页会继续承担入口和概览；关于页则留给更接近作者本人的说明。
